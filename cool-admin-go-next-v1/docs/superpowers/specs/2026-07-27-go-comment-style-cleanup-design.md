# Go 注释风格整理设计

## 范围

检查 `cool/` 与 `modules/` 下的 Go 源文件，只调整注释，不修改标识符、公开接口或运行逻辑。

## 规则

- 类型、变量和常量注释使用简短中文名词短语，不重复对应的 Go 标识符，不使用“xxx 是 xxx”的句式。
- 函数和方法注释使用中文动词短语说明用途，不重复函数名。
- 保留默认值、数量上限、调用顺序、兼容性、安全边界、错误条件和特殊返回语义等有效信息。
- 代码体内的注释解释处理原因，不复述相邻代码。
- 中文短注释不强制使用句号，较长的完整句子保留正常标点。

示例：

```go
// 中间件开关
type Switch struct {
	Enable bool
}

// 模块配置
type Config struct {
	AllowKeys []string
}

// 读取基础模块配置
func LoadConfig(ctx context.Context) Config {
	// ...
}
```

## 验证

- 搜索并人工复核残留的“标识符 + 是”机械注释。
- 检查差异，确认只包含注释调整。
- 运行 `go test ./...`、`go vet ./...` 和 `git diff --check`。
